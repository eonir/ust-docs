# Installation

1. Create a new project with the **Universal 3D** template, Unity 6000.3 or newer.
2. Import UST from the Package Manager (*My Assets*).
3. Let Unity install the dependencies and recompile.
4. Open the demo scene in `Assets/UST/Demo/Scenes`.

## Folder structure

```
Assets/UST
├── Core        Shared interfaces, spawn points
├── Player      Controller, input, camera, interaction
├── Vitals      Vitals, death and respawn
├── Inventory   Items, containers, world items, loot bags
├── Save        Save manager and player identity
├── Net         Network helpers and the debug session menu
├── Modules     Optional modules
├── Editor      Inspectors and tools
└── Demo        Demo scene and content
```
