# Requirements

| | Version |
|---|---|
| Unity | 6000.3 or newer |
| Render pipeline | URP 17.3 |
| Netcode for GameObjects | 2.13 |
| Multiplayer Services | 2.4 |
| Multiplayer Play Mode | 2.0 (editor testing) |
| Input System | 1.19 (the project must use the new Input System only) |
| Cinemachine | 3.1 |

The packages are listed as dependencies of the template and are installed automatically.

!!! warning "Input handling"
    *Project Settings > Player > Active Input Handling* must be set to **Input System Package (New)**. The legacy
    Input Manager is not supported.
