# Quick Start

## Play the demo alone

1. Open the demo scene.
2. Press **Play**.
3. Click **Host** in the session menu at the top of the screen.

## Play the demo with two players in the editor

1. Open *Window > Multiplayer > Multiplayer Play Mode* and enable **Player 2**.
2. Press **Play**. A second editor window opens for the virtual player.
3. Click **Host** in the main editor, then **Client** in the Player 2 window.

## Default controls

| Action | Keyboard and mouse |
|---|---|
| Move | WASD (ZQSD on AZERTY, keys are physical) |
| Look | Mouse |
| Sprint | Shift |
| Jump | Space |
| Crouch | C |
| Interact / pick up | E |
| Attack / gather | Left mouse button |
| Hotbar | Mouse wheel, 1 to 0 |
| Inventory | Tab, Escape to close |
| Move items | Drag and drop, right drag for half, Shift + click to send to the other side |
| Drop items | Drag out of the inventory window |
| Kill yourself (debug HUD) | K |

!!! note
    The session menu at the top of the screen is a debug tool drawn with IMGUI, meant for testing. The rest of the
    UI is uGUI, see [UI](../modules/ui.md).
